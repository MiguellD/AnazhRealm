## Die Bedienung des Gelände-Studios (Koordinator 11.10., Schöpfer: „das Beste, Atemberaubendste aus allen UIs“)
Das Studio ist das erste auf der Welt-Engine — seine Bedienung wird die Vorlage für alle folgenden. Maßstab (Prinzipien, keine Kopie):
- **Townscaper:** ein Griff, sofort Ergebnis; nie ein Dialog vor dem Bild. → Jeder Regler wirkt live (≤ 2 min bis zum gebauten Boden, die
  Makro-Ansicht sofort aus dem Kern).
- **Gaea / World Machine:** wenige starke Parameter mit sichtbarer Wirkung, Vorschau neben dem Regler. → 4 Haupt-Regler-Gruppen in Sprache des
  Bildes: KONTINENT (Land/Meer, Höhe), TÄLER (Flussnetz-Dichte, Talform U↔V), KLIFFS (Schicht-Gesetz), RAUHEIT (Rinnen/Grate). Alles Weitere
  hinter „mehr“.
- **Houdini:** Seed + Presets + Vergleich. → Saat-Würfel, 3–5 benannte Landschaften als Presets (Mittelgebirge, Alpental, Tafelland, Küste),
  A/B-Umschalter vorher/nachher am selben Ort.
- **Die Zahl gehört ins Bild:** die Gelände-Linse (Senken/km², sanfte Fenster, θ, Hang-Histogramm) live als kleine Leiste, grün im
  Natur-Korridor (Nordstern §4.1), rot außerhalb — der Gestalter sieht sofort, ob es „wahr“ ist.
- **Die Garage-Norm** (Studio-Vollendung Phase A: UI = garage) ist der Ausgangspunkt der Panel-Form; kein dritter Look-Pfad, die Welt-Engine
  zeichnet.
- **Atemberaubend ist das Gelände, nicht das Panel:** Panel schmal, halbtransparent, einklappbar; die Kamera fliegt (Makro-Flug, langsamer
  Orbit, Augenhöhe auf Knopfdruck).
Abnahme zusätzlich: ein Bild-Paar „Studio-Ansicht“ (Panel + Makro) und eine kurze Folge von 3 Bildern: Preset → Regler → Ergebnis.
